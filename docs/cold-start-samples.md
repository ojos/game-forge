  なぜこの順に回すか、商標の扱い）は **issue #43 のコメント**にあります。**ここへ複製しません。**

ルールは書きません。**足りないものが目に見える状態が、そのままツッコミどころと改造余地に
なります**（#43）。

**参考作の名前は書きません。** 骨組みは指定側（このお題）が持ちます。

## 3. 1 日目が終わったらやること

**2 日目の構成は、1 日目の実測で決め直します**（#43）。1 日目に測るのは次の 3 つです。

1. **実際のソース量**（64KB に対する余裕）
2. **所要時間**（1 本あたり。**送信から完成までの実測は 107 秒**——ただしこれは 2026-08-30、
   64KB へ上げる前の値である。時間予算の現行値は仕様 4.4 を見ること）
3. **費用**（`docs/usage-report.md` と `scripts/usage-report.sh`）

**6 がモデレーションで落ちた場合は、仕様 8.2 の実測表へ 1 行足してください**（暴力・不品行の
フィルタを外した v1.47 以降で落ちた初の記録になります）。

## 4. 公開と、そのあと

- **生成しただけでは誰にも見えません。** 作者プレビューで試遊し、**「公開」を押すまで URL は
  有効になりません**（5.4）。10 本とも公開すること
- **公開すると OGP を 1 回だけ撮ります**（5.4 / `docs/ogp-capture.md`）。撮影は 7.9〜16.9 秒で
  ぶれるので、`ogp_state` が `ready` になったかを確かめる
- **公開した時点で、トップの「公式サンプル」の節に出ます**（2.3.1 / 2.3.3。運営フラグが
  立っているため）。**節に出るのは各 8 件まで**なので、10 本すべては並びません
- **作品ページに「運営アカウント」のバッジが出ます**（#334。公開済みの作品だけ）

## 5. 音

**音は本番で鳴ります**（#306 は解決済み。2026-09-05 に利用者が確認）。**サンプルに音入りが
1 本も無いと、鳴ることが誰にも伝わりません。** 生成後に音が入っているかを見て、入っていない
なら**改造（フォーク）で足す**という手もあります（**フォークも 1 回分の生成枠と費用を使います**）。
**8 と 5 は音と相性が良い**（#43）。
