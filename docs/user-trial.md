# 知らない人の試用キット

**知らない人に Game Forge を一人で試してもらい、その様子を録画で受け取るための手順一式です**（#972）。

- 位置づけ: [strategy.md](strategy.md) 4 章の 1 を実行するための手順。なぜ試用するのか、結果で何を決めるのかは strategy.md にあり、ここへは書き写しません。
- 対象: 職場や友人のうち、仕様 2.1 のペルソナ（ネットミーム好き・大喜利好きの 20〜40 代）に近い人を 3 人。家族と開発者は外します。AI でゲームを作った経験がある人と無い人を混ぜます。
- 形: 試用者の端末で、画面と声を録画しながら一人で触ってもらいます。運営は横にいません。

**リポジトリは public です。** 録画・文字起こし・観察シート・行動の記録・試用者の名前やハンドルは、リポジトリに入れません。試用の控えは、リポジトリの外（Mac の手元など）に 1 人 1 フォルダで置きます。リポジトリに残してよいのは、名前を伏せた 7 章のまとめだけです。

---

## 1. 準備

| 何を | どうする |
|---|---|
| 招待コード | 運営アカウントでログインし、アカウントのメニューの「招待コードを発行する」（`/invites`）で 1 人 1 つ発行します。**招待枠は 3 本まで溜まり、使うと 30 日ごとに 1 本ずつ戻ります**（仕様 8.1）。3 人ぶん発行すると枠が空になります |
| 録画の受け取り先 | 録画を非公開の R2 へ上げる受け口（#973）ができていれば、その URL を 1 人 1 つ発行します。**できていなければ、AirDrop や手渡しで受け取ります**（共有のチャットに流すと圧縮され、声が聞き取りにくくなります） |
| 控えのフォルダ | リポジトリの外に、試用者ごとのフォルダを作ります（例: `~/game-forge-trial/p1/`）。名前ではなく `p1`〜`p3` の番号で呼びます |
| 試用者に渡すもの | 2 章の頼み方、3 章の同意、4 章の録画の手順のうち試用者の端末の分、招待コード、受け取り先 |

## 2. 頼み方（試用者へ送る文面）

**フォークのことは言いません。** 誰にも言われずにフォークを見つけて押すかどうかが、いちばん知りたいことの 1 つだからです（strategy.md 3.2）。説明しすぎると、知らない人の目で見たことになりません。

> 自分で作っている「Game Forge」というサイトを、試しに使ってみてもらえませんか。文章で頼むとブラウザゲームを作ってくれるサイトです。
>
> お願いしたいのは、**壊すつもりで、ダメな所を探してもらうこと**です。褒めてもらうより、つまずいた所や、がっかりした所を見つけてもらえるほうが助かります。
>
> - 時間は 20〜30 分くらいです。いつ触ってもらってもかまいません。
> - 触っているあいだ、画面と声を録画してください（やり方は下に書きます）。録画を始めたら、最初に「同意します」と声で言ってください（下の「録画の扱いについて」への同意です）。思ったことは独り言のように声に出してもらえると、とても助かります。「これ何？」「おっ」「めんどくさい」くらいで十分です。
> - 何をするかは自由です。使い方の説明はあえてしません。
> - 終わったら、最後にある質問に声で答えてから録画を止めてください。
>
> 招待コード: （ここにコード）
> サイト: https://app.game-forge.ojos.jp/
> 録画の送り先: （ここに受け取り先）

## 3. 同意（試用者へ送る文面）

頼み方と一緒に送ります。**録画を始めてから最初に**、声で「同意します」と言ってもらいます（録画に残すためです）。声で言いにくい人には、試用の前に返信で同意をもらい、その返信を控えのフォルダに残します。

> **録画の扱いについて**
>
> - **使い道:** Game Forge を良くするためだけに使います。公開しません。
> - **置き場所:** 運営（私）だけが読める、非公開の保存場所に置きます。
> - **保存期間:** 受け取ってから 90 日で消します。
> - **AI に渡すもの:** 録画から文字起こしと数秒おきの静止画を作り、内容の整理に AI（Anthropic の Claude）を使います。**音声そのものは外部のサービスへ送りません**（文字起こしは手元の機械で行います）。
> - **記事などに書くとき:** 名前は出しません。発言を引くときも、誰の発言か分からない形にします。
> - **作ったゲーム:** サイトで作ったゲームと、生成に使った文章は、通常の利用と同じくサイトに残ります（公開するかどうかは自分で決められます）。
> - **やめたいとき:** 途中でやめてかまいません。録画の削除は、いつでも頼めます。頼まれたら、受け取った録画と、そこから作った文字起こし・静止画をすべて消します。

**この文面は、受け口（#973）と分析（#974）の決定と一致させます。** 保存期間は #973 のバケットの自動削除の期間、AI に渡すものは #974 の作りです。どちらかを変えたら、この文面も同じ PR で直します。

## 4. 録画の手順（端末ごと）

試用者には、自分の端末の分だけを渡します。**ふだんゲームを遊ぶ端末で試してもらいます**（スマホで遊ぶ人に PC で試してもらうと、別の体験を測ることになります）。

**どの端末でも、マイクをオンにすることを忘れないでください。** 声の無い録画では、何に迷ったかが分かりません。機種や OS の版によって、項目の名前が少し違うことがあります。

### iPhone

1. 「設定」→「コントロールセンター」で「画面収録」を足します（すでにあれば不要）。
2. 画面の右上から下へなぞってコントロールセンターを開き、**画面収録のボタンを長押し**します。
3. **「マイク」をオン**にしてから「収録を開始」を押します。
4. 終わったら、画面上部の赤い表示を押して止めます。録画は「写真」に保存されます。

### Android

1. 画面の上から 2 回下へなぞって、クイック設定を開きます。
2. 「スクリーンレコード」（機種によっては「画面録画」）を押します。見つからなければ、クイック設定の編集から足します。
3. 音声の設定で **「マイク」** を選んでから開始します。
4. 終わったら、通知から止めます。録画はギャラリー（フォト）に保存されます。

### Mac

1. **Command＋Shift＋5** を押します。
2. 下に出るバーで「画面全体を収録」を選びます。
3. 「オプション」の「マイク」で、**内蔵マイク（MacBook のマイクなど）を選びます**。
4. 「収録」を押して始めます。終わったら、メニューバーの停止ボタンを押します。録画はデスクトップに保存されます。

### Windows

1. **Windows 11 なら、Snipping Tool の録画を使います。** Snipping Tool を開き、ビデオカメラの印（録画）を選び、録画する範囲としてブラウザの画面を囲みます。**マイクをオン**にしてから開始します。
2. Snipping Tool に録画が無い場合は、**Windows＋Alt＋R**（Xbox Game Bar）で録画を始め、**Windows＋Alt＋M** でマイクをオンにします。この方法はブラウザの窓だけを録るので、別のアプリへ移った所は映りません。
3. 録画は「ビデオ」の「キャプチャ」フォルダなどに保存されます。

## 5. 試用の流れ

試用者に渡す流れは 2 章の文面だけです。この章は、録画を見る側が「どの段で何が起きたか」を読むための区切りです。

| 段 | 時間の目安 | 試用者がすること | 運営が見ること |
|---|---|---|---|
| 0 | — | 2 章の文面を読み、録画を始めて同意を言う | 同意の発言があるか |
| 1 | 15 分 | 自由に触る | 最初に何をしたか。何を作ろうとしたか。どこで止まったか |
| 2 | 10 分 | 続けて自由に触る | 他人の作品を開いたか。**誰にも言われずにフォークを押したか**。共有しようとしたか |
| 3 | 5〜10 分 | 6 章の質問に声で答え、録画を止める | — |

**段 1 と段 2 は、試用者から見ると区切りがありません。** 横にいないので「ほかの人の作品も見てみてください」とは促せません。他人の作品を開かなかったら、それも結果です。

## 6. 振り返りの質問（試用者へ送る文面）

2 章の文面の最後に付けます。**意見ではなく、事実と行動を聞きます。** 「面白かったですか」と聞くと、知り合いは優しく答えます。

> **最後に、録画を止める前に、次の質問に声で答えてください。**
>
> 1. ChatGPT などの AI でゲームや何かを作ったことはありますか。あるなら、そのときと比べてどうでしたか。
> 2. 今日作ったものを、誰かに見せたいと思いましたか。思ったなら、誰にですか。
> 3. **不満を 3 つ挙げてください。** 小さなことでもかまいません。
> 4. いちばんがっかりしたのは、どの瞬間でしたか。
> 5. 次に使うとしたら、どんなときですか。「たぶん使わない」でもかまいません。

**「お金を払いますか」は聞きません。** 仮定の質問への答えは、実際の行動と一致しないからです。

## 7. 観察シート

録画を見ながら、1 人に 1 枚埋めます（控えのフォルダに置きます）。分析の段（#974）が下書きを作る場合も、この項目に沿います。

| 項目 | 記入の仕方 |
|---|---|
| 試用者 | `p1` などの番号。端末（iPhone / Android / Mac / Windows）。AI でものを作った経験の有無 |
| 同意 | 録画の中で同意を確かめた時刻（返信で同意をもらった人は、その旨） |
| 最初の 1 分 | 最初に何を見て、何を押したか |
| 作ろうとしたもの | お題の文面（8 章の行動の記録から写す）と、その意図を話していればその発言 |
| 止まった所 | 時刻・画面・何に迷ったか（発言を引く） |
| 反応 | 笑った・驚いた・がっかりした瞬間。時刻と、何に対してか |
| 他人の作品 | 開いたか。何本か。遊んだか |
| フォーク | **誰にも言われずに押したか**。押したなら、何を変えようとしたか |
| 共有 | URL のコピー、スクリーンショット、「見せたい」という発言があったか |
| もう一度 | 同じ作品を 2 回以上遊んだか。作り直したか |
| 質問への答え | 6 章の 5 問それぞれ（要約と、印象的な発言をそのまま） |
| 不満 3 つ | 6 章の 3 の答えをそのまま |
| 運営の気づき | 見ていて思ったこと。仮説につながりそうなこと |

## 8. 行動の記録を取り出す

録画では、生成のお題の文面が画面の端に小さく出るだけです。台帳から時刻つきで取り出し、録画と突き合わせます。

```bash
bash scripts/trial-timeline.sh --remote --handle <試用者のハンドル> > ~/game-forge-trial/p1/timeline.txt
```

- 出るのは、登録・生成とチャットの呼び出し（お題の文面つき）・作品の作成とフォーク・公開・版の 5 種類です。時刻は JST です。
- **いいねとプレイは出ません。** どちらも台帳には作品ごとの数しか無いためです（詳しくは [scripts/trial-timeline.sh](../scripts/trial-timeline.sh) の冒頭）。録画で見ます。
- **出力には試用者のお題の文面が載るので、リポジトリの外へ保存します。** 上の例のように、控えのフォルダへ書き出します。
- `--format json` で、分析の段（#974）へ渡す形でも出せます。

## 9. まとめの型

3 人の観察シートがそろったら、strategy.md の 3 つの仮説に一行ずつ答えます。**ここだけは名前を伏せたうえで、strategy.md に残してよいものです。**

| 仮説 | 一行の答え | 根拠（観察シートの番号と項目） |
|---|---|---|
| 改造したくなる体験こそが本体か（誰にも言われずにフォークしたか、他人の作品を開いたか） | | |
| 汎用の AI（ChatGPT など）より優れている点はあるか | | |
| 生成の品質が、使い続けることの障害になっているか | | |

そのうえで、strategy.md 4 章の 2「Game Forge にしか無いものを一行で」を書きます。3 人では結論を出せないこともあります。そのときは「分からなかった」と書き、何が分からなかったかを残します。それも 4 章の 3 の分かれ道の材料になります。
