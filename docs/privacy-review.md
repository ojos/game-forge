法律の専門家に確かめてもらうための資料です。

- 読み手: **確認をお願いする専門家。** 3 章が確かめていただきたい点、4〜6 章がその根拠になる事実です
- 対象の文面: <https://game-forge.ojos.jp/privacy>（本番）。文面の正本はリポジトリの `src/privacy.ts`
- 事実を確かめた日: **2026-09-14**（本番のデータベース・ファイル置き場・設定の読み取りと、コードの照合による）
- 結果の記録: 確認を受けたら 7 章に書き、指摘を `src/privacy.ts` に反映します（#460 の acceptance）

## 1. この資料の前提

- **いまの文面は、法律の専門家が書いたものではありません。** 画面にも「クローズドβ向けの暫定版」と出しています
- 文面には、**実際に取得・保存しているものだけ**を書いています。これから取得を始める項目は、始める変更と同じ変更で書き足す運用です
- 外部の事業者への送信は、**事実（誰へ何を送るか）だけを書き、法令上の区分は書いていません**（3 章の Q2）

## 3. 確かめていただきたいこと

### Q1. 運営者の表示

- 名称は暫定の「Game Forge 運営」で、**住所と代表者の記載がありません**
- 運営の形態（個人か法人か）と正式な名称・住所・代表者は、**運営側で決めてお伝えします**（下の欄）
- 伺いたいこと: 一般公開の段階で、本文に何を載せる必要があるか。個人の場合に住所を載せない選択が取れるか

> 運営側で記入: 運営の形態 ＿＿＿ / 正式名称 ＿＿＿ / 住所 ＿＿＿ / 代表者 ＿＿＿

### Q2. 外部の事業者への送信の区分

5 章の 4 事業者について、それぞれの送信が**業務の委託**にあたるか、**外国にある第三者への提供**にあたるか
（あるいはどちらにもあたらない保存の場所の利用か）を伺います。本文の 4 は「確認を受けて記載する」と書いたままです。

とくに判断を伺いたい点:

- **Cloudflare** は情報の主な保存先です。ファイル置き場（R2）の位置の指定は「APAC」で、特定の国には固定していません
- **AWS** の生成は、日本国内のリージョンに限る設定で呼んでいます。一方、指示文の有害性の検査は、**アジア太平洋の複数のリージョン**で処理される設定です（本文の 5 に書いてあります）
- **Resend**（メール送信）と **Google**（ログイン）は米国の事業者です。Resend のデータの処理地域は未確認です

### Q3. M12（2026-09-12〜13）で増えた項目の書き方

いずれも本文の 1・3・6・7 に書き足し済みです。書き方が足りているかを伺います。

| 項目 | 伺いたい点 |
|---|---|
| 自己紹介と外部リンク | **誰でも見られる。** 外部リンクは本人の申告で、運営はリンク先が本人のものか確かめていない |
| アイコン画像 | 誰でも見られる。**差し替える前の画像を 30 日保存する**（通報への対応のため）。撮影場所などのメタデータは作り直すときに取り除く |
| ハンドル名とその履歴 | 誰でも見られる。**改名から 90 日は旧い URL を新しい URL へ転送するため、前後のハンドル名が同じ人のものだと第三者に分かる** |
| プレイ数と sessionStorage | 起動回数は誰とも結び付けずに数える。重複を避けるために、**ブラウザの sessionStorage に時刻を置く（Cookie ではなく、サーバへ送らない）** |
| メール配信の設定 | 改造のお知らせは止められる。**生成の完了・失敗のお知らせは、設定にかかわらず送る** |

### Q4. 変更の履歴を削除しない保存

表示名・自己紹介とリンク・アイコン・ハンドル名・作品の題名と説明の**変更の履歴は、通報への対応のために追記だけで残し、期限を定めずに保存しています**（公開はしません）。
本人から削除の請求があった場合との関係で、この保存の仕方と書き方でよいかを伺います。

### Q5. 保存期間を定めていない情報と、退会の機能が無いこと

- 本文の 7 は、期限を定めた自動の削除を行う情報（6 章）以外を「提供に必要なあいだ保存します」としています
- **利用者自身で退会する機能はありません。** 削除の希望はメールで受け、運営が端末の手順で消します
- 伺いたいこと: 一般公開の前に、保存期間の書き方を改める必要があるか。退会の機能が無い状態での書き方として足りているか

### Q6. 開示などの請求の本人確認

本文の 8 は「登録しているメールアドレスから送ってください」としています。本人確認の方法としてこれでよいかを伺います。

### Q7. IP アドレスなどの記述

本文の 1 は「閲覧した画面の履歴・IP アドレス・ブラウザの種類を、**自らのデータベースへ保存していません**」としています。
これは事実です（本サービスのデータベースには、それらの列がありません）。ただし、配信を担う Cloudflare や AWS が、
各社のサービスの一部として接続の記録を扱うことはありえます。この書き方で誤解を招かないかを伺います。

### Q8. 年齢

利用できる年齢の定めがありません（2 章）。未成年の利用について、本文または規約に書く必要があるかを伺います。

### 範囲の外

- **特定商取引法に基づく表記**（金銭の受け取りが無いため）
- **利用規約（`/terms`）の全面改訂。** 規約も暫定版で、一般公開の前に確認が要ることは分かっています。同じ機会に見ていただくかは、運営が別に決めます

## 4. 取得・保存している情報（事実）

「公開」は、ログインしていない人を含め誰でも見られることを指します。

| 情報 | 公開 | 保存先 | 保存期間 |
|---|---|---|---|
| Google アカウントの識別子・メールアドレス・名前 | メールは非公開 | Cloudflare D1 | 定めなし |
| 表示名 | 公開 | Cloudflare D1 | 定めなし |
| 表示名の変更の履歴 | 非公開 | Cloudflare D1 | 定めなし（追記のみ） |
| 自己紹介と外部リンク（3 本まで） | 公開 | Cloudflare D1 | 定めなし |
| 自己紹介と外部リンクの変更の履歴 | 非公開 | Cloudflare D1 | 定めなし（追記のみ） |
| アイコン画像（256px 四方の WebP に作り直したもの） | 公開 | Cloudflare R2 | 定めなし |
| 差し替える前・外す前のアイコン画像 | 非公開 | Cloudflare R2 | **30 日で自動削除** |
| アイコンの変更の履歴（画像のハッシュ値と日時） | 非公開 | Cloudflare D1 | 定めなし（追記のみ） |
| ハンドル名 | 公開 | Cloudflare D1 | 定めなし。手放した名前は 90 日予約し、その後もほかの人が取るまで残る |
| ハンドル名の変更の履歴 | 非公開 | Cloudflare D1 | 定めなし（追記のみ） |
| メール配信の設定と、止めた日時 | 非公開 | Cloudflare D1 | 定めなし |
| 招待（コード・誰が誰を招待したか・使った日時） | 非公開 | Cloudflare D1 | 定めなし |
| 作品を作るときの指示文 | 非公開 | Cloudflare D1 | 定めなし |
| 作品（題名とその変更の履歴・ソースコード・遊ぶためのファイル・紹介用の画像・公開の状態・改造元） | 公開した作品は公開 | Cloudflare D1・R2 | 定めなし |
| 作品の説明とその変更の履歴 | 説明は公開、履歴は非公開 | Cloudflare D1 | 定めなし（履歴は追記のみ） |
| いいね（どの作品に・いつ）と 1 日の操作回数 | 数だけ公開 | Cloudflare Durable Objects | 定めなし |
| プレイ数（作品ごとの起動回数。利用者と結び付けない） | 公開 | Cloudflare Durable Objects・D1 | 定めなし |
| 通報（作品・理由・**通報した利用者**） | 非公開 | Cloudflare D1 | 定めなし |
| 生成の記録（日時・モデル・トークン数・費用・成否） | 非公開 | Cloudflare D1 | 定めなし |
| 入力の検査で止めた指示文と、止めた理由の分類 | 非公開 | Cloudflare D1 | **90 日を目安に削除**（運営が手順で消す。自動ではない） |
| 登録日時・運営が行った措置とその理由 | 非公開 | Cloudflare D1 | 定めなし（措置の記録は追記のみ） |
| 処理の記録（ログ） | 非公開 | AWS CloudWatch Logs | **14 日**（生成・ビルド・撮影・アイコンの作り直し）/ **30 日**（費用の上限の監視）で自動削除 |
| 待機リスト（メールアドレスと、登録した画面） | 非公開 | Cloudflare D1 | 定めなし |
| 削除依頼（名前または団体名・連絡先・依頼の内容。本人確認はしていない） | 非公開 | Cloudflare D1 | 定めなし |
| お問い合わせのメール | 非公開 | 窓口のメールボックス | 定めなし |

**取得していないもの:** パスワード、Google のプロフィール画像、閲覧履歴・IP アドレス・ブラウザの種類（本サービスのデータベースには保存していない。Q7）、アクセス解析や広告のための情報。

## 5. 外部の事業者（事実）

| 事業者 | 使い方 | 送る・保存する情報 | 処理・保存の地域 |
|---|---|---|---|
| **Cloudflare** | 配信、データベース（D1）、ファイル置き場（R2）、いいねとプレイ数の記録（Durable Objects） | 4 章のうち、ログを除くほぼすべて | R2 の位置の指定は **APAC**。D1 の読み取りは APAC の主系が応答している。配信は各地のデータセンター |
| **Amazon Web Services（AWS）** | 生成（Amazon Bedrock。Anthropic 社の Claude モデル）、指示文の有害性の検査（Bedrock Guardrails）、ビルド、紹介用の画像の撮影、アイコンの作り直し、処理の記録（ログ） | 指示文、改造・推敲のときは元の作品のソースコード、アイコンの画像（作り直すあいだだけ。AWS 上に保存しない） | 生成は **日本国内**のリージョンに限る設定。**検査はアジア太平洋の複数のリージョン**で処理されうる設定。そのほかは東京リージョン |
| **Google** | ログイン（OAuth） | 本サービスから送る利用者の情報は無い（識別子・メールアドレス・名前を受け取る側） | 米国の事業者 |
| **Resend** | お知らせのメールの送信 | 宛先のメールアドレスと、本文（作品の題名など） | 米国の事業者。**データの処理地域は未確認** |

**補足:** 生成のモデルは設定で DeepSeek（Bedrock 上で提供されるモデル）へ切り替えられる作りですが、
**本番では一度も使っていません**（2026-09-14 時点で、本番の生成 56 回はすべて Claude）。切り替える場合は、本文の 5 を先に直します。

## 6. Cookie とブラウザの保存領域（事実）

| 名前 | 中身 | 期間 | 備考 |
|---|---|---|---|
| ログインの状態（Cookie） | 利用者の識別子と有効期限。改ざんを検知できる形 | 7 日 | 本サービスのドメインだけに送られ、ページのスクリプトからは読めない |
| ログイン手続き中の情報（Cookie） | Google との往復のあいだの一時情報。入力された招待コードと、ログイン後に戻る画面を含む | 10 分 | 同上 |
| プレイ数の重複防止（sessionStorage） | 作品ごとに最後に数えた時刻 | タブを閉じるまで | Cookie ではない。サーバへ送らない |

アクセス解析や広告のための Cookie と、外部のスクリプトは使っていません。
